## Philosophy

I am interested in technologies that can move beyond incremental improvement and become **foundations for entirely new systems**.

That means thinking simultaneously at multiple scales:

**micro → system → infrastructure → civilization**

A processor matters.

An AI model matters.

A power plant matters.

A city matters.

But the most interesting question is:
